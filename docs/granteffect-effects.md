# Supported `/granteffect` effects

These are the vanilla Terraria buff and debuff IDs in the TerrariaServerAPI revision pinned by this repository (`33cbc2a598a7173f63e23d420b70f1be17f27844`). The names come from Terraria’s English `Lang.GetBuffName` at runtime.

Use `/granteffect <effect name or ID> <online player> <seconds>` through chat or `/v3/server/rawcmd`. Quote names with spaces, for example `/granteffect "Obsidian Skin" Alice 60`. `/granteffect list` returns this list from the running server, which may differ if its Terraria version changes. Several effects share a display name; use an ID to select a specific one. For example, `Zapped` is both `399` and `400`.
